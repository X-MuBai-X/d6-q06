# acceptance-audit

## 1. 用途

把题面与共同要求拆成**可机器判定**的检查项，逐条核对并给出证据位置；
产出「检查项明细.md」与结构化 JSON，供交付前自查、整改后复验与独立验收使用。

本 Skill **只判定，不修代码**；发现问题只报告与给复验条件。

## 2. 触发场景

- 交付前自查（合并 PR 之前）；
- 按题目清单核对 R1–R8 与共同要求；
- 独立测试 Agent 提出缺陷并修复之后复验；
- 生成验收材料（逐项结论 + 证据位置）。

## 3. 输入

| 参数 | 说明 | 默认 |
|---|---|---|
| `--repo` | 仓库根目录 | 自动向上查找（当前工作目录） |
| `--out-dir` | 输出目录 | `<repo>/evidence/acceptance-audit` |
| `--min-coverage` | 覆盖率下限 | 85 |
| `--skip-toolchain` | 跳过需要 Go 工具链的检查（格式、vet、单测） | false |

## 4. 执行步骤

1. 定位仓库根目录；读取 `docs/_question-06.md`（题面快照）与 `AGENTS.md`；
2. 加载检查清单：
   - **业务规则类 8 项**：R1 描述快照、R2 幂等与唯一处理中任务、R3 失败与次数上限、
     R4 回调鉴权与幂等、R5 复核与确认采用、R6 版本历史、R7 撤销、R8 权限与核查；
   - **共同要求类 10 项**：数据库持久化、最小业务页面、模拟供应商四类场景、
     阶段产物齐备、AGENTS 版本与读取记录、两个自编 Skill 七要素、
     覆盖率 ≥85%（整体与各核心包）、提交消息格式、泄密扫描无白名单、自动部署与冒烟记录；
   - **凭据专检 1 项（C-14）**：已知演示凭据明文只允许出现在 `cmd/server/main.go`；
3. 逐项判定：
   - **源码模式类**：在指定文件里查找关键实现（常量、状态集合、索引、鉴权代码）；
   - **证据存在类**：检查证据文件是否存在且非空；
   - **泄密扫描类**：**已知凭据值检测 + 敏感形态检测**双保险
     （已知值在运行时从 `cmd/server/main.go` 读取后逐文件比对，形态检测保留 `ghp_`／`ghu_`／
      `github_pat_`／`Bearer`／`Authorization`／私钥／口令赋值／密钥赋值／Cookie 值等正则；
      全量扫描 `evidence/` 与 `docs/`，另对仓库全量扫描 C-14，**不使用白名单或例外目录**），
     命中信息只以**掩码**展示凭据值，避免报告本身造成二次泄漏；
   - **工具链类**：`gofmt -l .`、`go vet ./...`、`go test ./...`（可用 `--skip-toolchain` 关闭）；
4. 汇总判定并落盘。

## 5. 输出格式

- `检查项明细.md`：表格（编号 / 类别 / 规则 / 名称 / 结论 / 证据 / 复验方式）+ 待补证清单 + 未通过项；
- `acceptance-audit.json`：结构化（`items[]` 含 `id`／`category`／`rule`／`status`／`evidence`／`verify`）。

结论取值：`PASS` / `FAIL` / `待补证`。
**存在任一 FAIL 时总判定为 FAIL。**

## 6. 失败处理

- 缺证据即判 `FAIL`，并在「复验方式」写明需要补什么；
- 环境受限（无 Go 工具链、无线上环境）判 `待补证` 并写明原因 ——
  **「没做」与「做不了」必须分开陈述**；
- 证据中出现明文口令/密钥、令牌、Cookie 直接判 `FAIL`；
- 泄密检测**按已知凭据值判定**（不依赖书写格式），且命中信息里的凭据值一律掩码；
  禁止用白名单/例外目录规避扫描，也禁止把明文凭据写进本 Skill 自身文件；
- **禁止放宽标准**：发现检查项本身有缺陷时，**修检查项并在报告中留痕**（写明修改前后的判定差异与原因）；
- 脚本自身异常（读不到仓库、依赖缺失）时输出 `待补证`，**不得**输出 PASS。

## 7. 完成标准

- 全部检查项都有结论（PASS / FAIL / 待补证）；
- PASS 项有可回源的证据位置（文件:行号 / 证据文件路径 / 命令输出路径）；
- FAIL 项有具体不满足点与复验方式；
- 待补证项写明原因与补证办法；
- **存在 FAIL 时总判定必须为 FAIL**；
- Markdown 与 JSON 两份结果都已落盘。
