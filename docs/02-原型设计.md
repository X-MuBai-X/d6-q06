## 1. 原型要覆盖的四个范围（题面原文）

| 题面要求 | 对应页面 | 路由 |
|---|---|---|
| 需求工作台 | 创建需求、查看我的需求与状态、进入详情 | `/workbench` |
| 候选复核 | 待复核队列、查看当前候选、给出通过/不通过及原因 | `/review`、`/requirements/{id}` |

| 运营异常查询 | 异常回调、失败与超时任务、状态分布、跟进意见 | `/ops` |

## 2. 页面状态说明（含异常状态）

### 2.1 登录页 `/login`

| 元素 | 说明 |
|---|---|
| 输入 | 账号、口令；`next` 隐藏域用于登录后回跳 |
| 正常态 | 登录成功 → 写会话 Cookie → 跳转 `/workbench` |
| 异常态 | 账号或口令不正确 → 401，页面顶部红色提示「账号或口令不正确」，不清空账号输入 |
| 异常态 | 未登录访问受保护页面 → 302 到 `/login?next=…` |
| 异常态 | 未登录访问 JSON 接口 → 401 JSON `{"ok":false,"error":"未登录或会话已失效"}` |

### 2.2 需求工作台 `/workbench`

| 区块 | 内容 | 状态 |
|---|---|---|
| 新建素材需求 | 活动名称、用途、图片描述三个必填项 | 提交失败 → 回到工作台并显示红色错误（如「图片描述至少 4 个字符」）；成功 → 绿色提示 |
| 我的需求列表 | 活动名称、状态标签、用途、已发起次数（n/3）、详情链接 | 需求人只看到**自己**的需求；复核人与运营看到全部需求 |

### 2.3 需求详情页 `/requirements/{id}`（核心页面）

| 区块 | 内容 | 关键状态 |
|---|---|---|
| 需求信息 | 状态标签、用途、**当前描述**、已发起次数、需求 ID | 状态标签覆盖 9 种状态（`draft`/`generating`/`candidate_pending`/`rejected`/`approved`/`delivered`/`failed`/`exhausted`/`withdrawn`） |
| **当前候选** | 大图、版本号（第几次生成）、复核状态、复核原因 | 复核人可直接在此给出通过/不通过；**无当前候选时显示「当前没有待复核的候选」** |
| **历史候选**（题面 R6 要求分区） | 历史版本号、复核结论、原因、缩略图 | 历史版本标注「历史」，**不提供任何复核/确认按钮**，避免"展示旧图却操作新任务" |
| 生成历史 | 每次生成的序号、状态、供应商任务号、**当时的描述快照**、结果图或失败原因 | 失败原因直接显示（如「模拟供应商本次拒绝受理」「超过 6s 未收到有效终态，判定为超时」） |
| 可执行操作 | 发起生成（含请求编号输入）、修改描述、确认采用、提出重做原因、撤销、运营跟进意见 | 按钮按「角色 × 状态」矩阵显隐；操作失败 → 红色提示原因为由（如「该候选已是历史版本，不能复核」） |
| 审计时间线 | 时间、事件类型、详情 | 覆盖创建、发起生成、回调受理、候选生成、复核、采用、撤销、迟到结果、重复回调等 |

### 2.4 候选复核页 `/review`

| 区块 | 内容 | 状态 |
|---|---|---|
| 待复核队列 | 活动名称、状态、用途、进入链接 | 只列 `candidate_pending` 的需求；空队列显示「当前没有待复核的需求」 |
| 提示 | 底部固定说明「复核对象只能是该需求的当前候选；上一版候选只作历史，不能再复核」 | 常驻 |

### 2.5 运营异常查询页 `/ops`

| 区块 | 内容 | 状态 |
|---|---|---|
| 需求状态分布 | 9 种状态各自的数量 | 空库时各行为 0 |
| 生成任务状态分布 | 5 种状态各自的数量 | 同上 |
| 异常记录 | 时间、异常类型（重复回调／冲突回调／迟到结果被忽略／回调关联不到任务／回调签名无效／生成失败／生成超时／生成未受理）、需求链接、详情 | 空时显示「暂无异常记录」 |
| 全部需求的生成与处置 | 活动名称、状态、发起次数、当前候选、详情链接 | — |
| 最近事件 | 最近 20 条事件 | — |

### 2.6 演示图片 `/static/img/{name}.svg`

- 平台本地生成 SVG 演示图，**不依赖外部网络**；
- 图片名只允许 `[A-Za-z0-9_-]+`，非法名返回 400；
- 候选与生成结果中的图片地址即指向该路由。

## 3. 页面—规则—异常对应表

| 页面区块 | 支撑规则 | 必须可见的异常信息 |
|---|---|---|
| 发起生成 | R2 | 「该需求已有处理中的生成任务」「该请求编号已存在或已有处理中任务」「已发起 3 次生成，达到上限」 |
| 修改描述 | R1 | 「当前状态 generating 不允许修改描述」 |
| 当前候选复核 | R5,R6 | 「复核不通过必须填写原因」「该候选已是历史版本，不能复核」「当前状态 approved 不允许复核」 |
| 确认采用 | R5,R7 | 「当前状态 candidate_pending 不允许确认采用」「只有需求人可以确认采用」 |
| 撤销 | R7 | 「当前状态 delivered 不允许撤销」 |
| 生成历史 | R3,R4 | 失败/超时原因、供应商任务号、迟到结果说明 |
| 审计时间线 | R4,R7 | 重复回调、冲突回调、迟到结果被忽略、签名无效 |
| 运营异常查询 | R4 | 异常类型、需求定位、处理意见记录入口 |
