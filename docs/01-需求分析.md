## 2. 业务流程与状态说明

### 2.1 需求状态机

```
                    创建
                     │
                     ▼
                 [draft 待发起生成]
                     │ 需求人发起生成（第 1 次）
                     ▼
              [generating 生成中] ─── 供应商拒绝/失败/超时 ──→ [failed 失败或超时]
                     │  │                                        │ 需求人改描述再发起（≤3 次）
                     │  │                                        ├──────────┐
                     │  │ 成功回调                               │          │ 第 3 次仍未成功
                     │  ▼                                        ▼          ▼
                     │  [candidate_pending 待设计复核] ← 改描述再发起  [failed] [exhausted 次数用尽]
                     │     │ 复核不通过（写原因）                  │          │
                     │     └────────→ [rejected 待重做] ─────────┘          │
                     │     │ 复核通过                                    │
                     │     ▼                                             │
                     │  [approved 待确认采用]                            │
                     │     │ 需求人确认采用          需求人提出重做原因      │
                     │     ▼                            │                │
                     │  [delivered 交付完成] ←──────────┴──→ [rejected] ─┘
                     │
                     └── 任一非终态 ── 需求人撤销 ──→ [withdrawn 已撤销]
```

- 终态：`delivered`（交付完成）与 `withdrawn`（已撤销）。
- `withdrawn` 之后，供应商迟到回来的成功或失败结果**只写入审计事件**，不改写需求状态、不产生候选（R7）。
- `exhausted` 之后不可再次发起（R3 的三次上限）。

### 2.2 生成任务状态机

```
[processing 处理中] ──成功回调──→ [succeeded 成功]（生成候选，等待复核）
        │
        ├──提交被拒──→ [rejected 被拒绝]
        ├──失败回调──→ [failed 失败]
        └──60 秒无有效终态──→ [timeout 超时]
```

- 任务进入终态后，**任何**迟到或冲突回调都不再改写它，只留审计（R4）。
- `rejected`/`failed`/`timeout` **一律不产生候选**（R3）。

### 2.3 候选版本规则

- 每个 `succeeded` 任务产生**一个**候选；候选带 `attempt_no`（第几次生成）与 `is_current`（是否当前版本）。
- 发起下一次生成时，旧候选 `is_current` 置 0 → 只作历史，不可再复核、不可再确认（R6）。
- 复核结论：`pending` → `approved`（需求可确认采用）或 `rejected`（必须写原因，需求可重做）。

### 2.4 角色—动作—允许状态矩阵

| 动作 | 需求人（本人需求） | 设计复核人 | 运营 |
|---|---|---|---|
| 创建需求 | ✅ draft | ❌ | ❌ |
| 修改描述 | ✅ draft/failed/rejected/approved | ❌ | ❌ |
| 发起生成 | ✅ draft/failed/rejected/approved | ❌ | ❌ |
| 复核当前候选 | ❌ | ✅ candidate_pending | ❌ |
| 复核历史候选 | ❌ | ❌ 409（版本已过期） | ❌ |
| 确认采用 | ✅ approved | ❌ | ❌ 403 |
| 提出重做原因 | ✅ approved | ❌ | ❌ |
| 撤销 | ✅ 除 delivered/withdrawn 外 | ❌ | ❌ |
| 查看生成与异常记录 | ❌ 他人需求 | ✅ 只读 | ✅ 只读 |
| 记录跟进意见 | ❌ | ❌ | ✅ |
