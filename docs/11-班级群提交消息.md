   任何具体数字编号在核验前都不得出现在群消息里。
5. **令牌与口令**：消息中不出现 GitHub 令牌（形式统一写作 `ghp_****`）与任何完整口令；
   演示口令的完整值只保留在 `cmd/server/main.go`。
