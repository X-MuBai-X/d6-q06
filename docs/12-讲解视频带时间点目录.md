## 8. 录制注意事项

1. **不要念出口令**：页面与文档里都是掩码（`docs/04-部署与使用说明.md` §3.1），
   完整值只在源码 `cmd/server/main.go:24`；录制时从源码读取即可。
2. **不要展示任何令牌**：GitHub 令牌只经环境变量传入，屏幕上不得出现；文档中统一写作 `ghp_****`。
3. **异常分支一定要展示状态码**：403 / 409 / 413 类提示（409 为主：处理中任务、次数上限、历史候选、
   状态不允许）是本题的核心考察点，每条都要念出**提示文案**而不只是状态码。
4. **必须覆盖五组场景**（S1–S5）；时间不够时，压缩 §7 收尾，不要压缩场景。
5. **必须交代两处环境事实**：① 模拟供应商是**可控 HTTP 模拟服务**，不是真实第三方接入；
   ② 演示图片是**平台本地生成的 SVG**，不是真实生图（题面单日边界）。
